{{- if $mcp }}

### Brancher l'Atelier dans un assistant (MCP)

Adresse du connecteur :

```
{{ $base }}/mcp
```

Authentification OAuth : au premier branchement, une page s'ouvre et demande
la clé owner, une fois. Aucun en-tête `Authorization` à écrire dans la
configuration du client.

Claude Code :

```bash
claude mcp add atelier --transport http {{ $base }}/mcp
```

Cursor (`.cursor/mcp.json`) :

```json
{
  "mcpServers": {
    "atelier": {
      "type": "http",
      "url": "{{ $base }}/mcp"
    }
  }
}
```

Claude (web, bureau, mobile) : Paramètres > Connecteurs > Ajouter un
connecteur personnalisé, avec la même adresse.
{{- end }}

Tout ce qui compte vit dans le volume `~/work` : projets, conversations,
secrets, réglages. Il survit à la suppression du service.

Documentation : [nic01asfr.github.io/atelier-sspcloud](https://nic01asfr.github.io/atelier-sspcloud/)
{{- else }}

from a terminal in the pod.

{{- if $mcp }}

### Connect the Atelier to an assistant (MCP)

Connector address:

```
{{ $base }}/mcp
```

OAuth authentication: on first connection, a page opens and asks for the
owner key, once. No `Authorization` header goes in the client configuration.

Claude Code:

```bash
claude mcp add atelier --transport http {{ $base }}/mcp
```

Cursor (`.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "atelier": {
      "type": "http",
      "url": "{{ $base }}/mcp"
    }
  }
}
```

Claude (web, desktop, mobile): Settings > Connectors > Add custom connector,
with the same address.
{{- end }}

Everything that matters lives on the `~/work` volume: projects, conversations,
secrets, settings. It survives deleting the service.

Documentation: [nic01asfr.github.io/atelier-sspcloud/en](https://nic01asfr.github.io/atelier-sspcloud/en/)
{{- end }}
