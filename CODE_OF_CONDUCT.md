# Code de conduite

Ce projet adopte le [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/),
version 2.1, dont voici l'essentiel.

## Engagement

Nous faisons de la participation à ce projet une expérience sans harcèlement
pour tout le monde, quels que soient l'âge, le handicap, l'origine, l'identité
ou l'expression de genre, le niveau d'expérience, l'éducation, la situation
sociale, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Ce qui est attendu

- faire preuve de bienveillance et de respect ;
- accepter les désaccords et les critiques constructives ;
- reconnaître ses erreurs et en tirer les leçons ;
- privilégier ce qui sert la communauté plutôt que soi.

## Ce qui n'est pas acceptable

- les propos ou images à caractère sexuel, les avances non sollicitées ;
- le trollage, les insultes, les attaques personnelles ou politiques ;
- le harcèlement, public ou privé ;
- la publication d'informations privées d'autrui sans son accord ;
- tout comportement raisonnablement jugé inapproprié dans un cadre
  professionnel.

## Signaler

Un comportement contraire à ce code se signale en privé au mainteneur, par le
signalement privé de GitHub (onglet **Security**, « Report a vulnerability »,
en précisant qu'il s'agit du code de conduite) ou par le contact indiqué sur
son profil GitHub. Chaque signalement est examiné, dans la discrétion.

Le mainteneur peut retirer ou refuser un commentaire, un commit ou une
contribution contraire à ce code, et exclure temporairement ou définitivement
une personne dont le comportement l'enfreint.
